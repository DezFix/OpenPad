## Что это

OpenPad — саундборд: жмёшь кнопку/хоткей — играет звук.
Два выхода **одновременно**:

- 🔊 **Динамики/наушники** — работает из коробки, ничего ставить не надо;
- 🎤 **Виртуальный микрофон** — для Discord / игр / голосовых чатов.

Плюс: глобальные хоткеи (работают без фокуса), категории, поиск,
громкость на звук, оверлэп / стоп повторным нажатием, сквозной микрофон.

## Честно про микрофон (важно!)

Частый миф: «Soundpad выводит звук через микрофон и ничего левого не ставит».

Правда: **Soundpad при установке ставит свой драйвер
«Soundpad Virtual Audio Device»**. Это и есть «то самое левое» —
просто оно bundled и подписано цифровой подписью.

У open-source проекта нет бесплатного подписанного kernel-драйвера
(нужен EV-сертификат ~$300/год + attestation Microsoft), поэтому OpenPad
делает так же, но открыто:

1. Из коробки — звук в твои наушники (драйверов не надо).
2. Для Discord — ставишь **VB-Cable** (бесплатно, 1 минута,
   [vb-audio.com](https://vb-audio.com/Cable/)) и выбираешь его
   в OpenPad как «Вирт. микрофон». В Discord микрофоном ставишь
   **CABLE Output**. Галка «Сквозной микрофон» пробрасывает твой живой
   голос туда же — друзья слышат и тебя, и мемы.

Подробно: в приложении **Помощь → Как вывести в микрофон…**

## Установка (Windows, Python 3.10+)

```bash
pip install -r requirements.txt
python run.py
```

Зависимости: `PyQt6`, `sounddevice`, `soundfile`, `numpy`, `pynput`.

`sounddevice` требует PortAudio — на Windows ставится колесом вместе
с пакетом, ничего дополнительно делать не надо.

Поддерживаются: `.wav .mp3 .ogg .flac .m4a .aac .opus .wma .mp4`
(`.mp4/m4a/aac/wma` — через `soundfile`, а если не встанет —
через `ffmpeg` из PATH).

## Использование

| Действие | Как |
|---|---|
| Добавить звуки | Кнопка ＋ / Ctrl+O / перетащить файлы в окно |
| Играть / стоп | Двойной клик, Space, кнопка ▶ |
| Стоп всё | ⏹ / Escape |
| Глобальный хоткей | ПКМ → Горячая клавиша… (работает без фокуса) |
| Категория | ПКМ → Категория… / список слева |
| Громкость звука | ПКМ → Громкость |
| Устройства | Верхняя панель: динамики + вирт. микрофон + гейны |

Настройки и библиотека хранятся в `%APPDATA%\OpenPad\`
(`library.json`, `config.json`) и переживают обновления.

## Структура

```
run.py                  # python run.py
src/openpad/
  app.py                # run()
  ui_main.py            # главное окно PyQt6
  audio_engine.py       # DualOutputEngine + MicPassthrough
  audio_loader.py       # soundfile + ffmpeg-fallback, 44100 stereo
  devices.py            # перечисление WASAPI-устройств
  library.py            # модель Track + JSON-персистентность
  hotkeys.py            # Qt -> pynput нормализация, GlobalHotkeys
tests/test_basic.py     # python -m unittest
```
